# تقرير الإنتاج بالساعة V10 (PWA)

المجلد يحتوي على:
1. `shift-report-v10.html` — واجهة تسجيل الإنتاج والسلايتات ومقاسات الخطوط (Line 1: 250/300، Line 2: 300/330/355).
2. `manifest.json` — ملف تعريف التطبيق لتثبيته كـ PWA.
3. `sw.js` — Service Worker للعمل بدون إنترنت وتخزين الملفات محلياً.

## طريقة التثبيت على الموبايل أو الكمبيوتر:
- ارفع الملفات الثلاثة (`shift-report-v10.html`, `manifest.json`, `sw.js`) إلى استضافة مجانية تدعم HTTPS (مثل GitHub Pages أو Vercel أو Cloudflare Pages).
- افتح الرابط في متصفح **Google Chrome** ثم اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
